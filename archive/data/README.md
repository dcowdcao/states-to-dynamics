# data/

`activations/` holds the extracted eval tensors (layer-5 activations + ground-truth board
states, legal moves, predicted moves, game tokens) written by `spade.extraction`. The `.pt`
tensors are gitignored (regenerated by the extraction stage); `metadata.json` is tracked.

Every other directory here is `$SPADE_DATA_ROOT`'s default (`spade.common.study`): the
study trees (`spade_<study>/`) and downloaded weights (`karvonen_saes/`), all gitignored.
