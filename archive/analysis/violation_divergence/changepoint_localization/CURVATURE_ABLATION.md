# Curvature in place of step length, through the identical pipeline

`theta_ablation.py`. Run 2026-08-20. The study's statistic is a one-sided **step-length**
drop; the README asserted that curvature "scores 0.53-0.58 and only in the straighter
direction" but no committed code ever loaded `theta` (`measure.py`'s `steps()` hardcodes
`["d"]`), so that number had no artifact behind it. This runs the real ablation: same
`profile -> drop -> scan -> max/argmax`, same `m = 4`, same paired MOSUM contrast, same
corpus, same seed, `theta` substituted for `d`.

## Validation

Reproducing the published table with `d` on its native 34-candidate window gives
GatedAnneal **0.6037** [0.578, 0.629] against the committed [0.578, 0.630], raw L5
**0.5575**, hit **0.3322**, shift-chance **0.0199** — identical to
`results/changepoint_localization.csv`. The reimplementation is faithful, so the `theta`
numbers below are like-for-like.

`theta` has width 56 against `d`'s 57 (an angle needs two consecutive displacements), so
both were re-run on a **matched 33-candidate window** (move indices 14-46) to hold the scan
window and chance level identical. `d`'s numbers move by <0.003 between the two windows.

Index convention is unchanged: `theta[a]` is the turn at the vertex at position `a+2`, the
same `CAND_OFFSET = 2` as `d[a]`, so the first angle influenced by the move at `c` is
`theta[c-2]`.

## Three findings

**Curvature cannot localize the splice at all.** Every `theta` hit rate is 0.018-0.056
against a shift-chance of 0.027-0.030 — chance. Step length puts GatedAnneal at 0.336,
about 16x chance. This is the cleaner half of the result: detection AUROC is a noisy
extreme-value statistic, the hit rate is not, and on the hit rate curvature is simply dead.

**Detection is near-dead too.** Seven of nine `theta` CIs include or nearly touch 0.5. The
best curvature space (CosineSpaDE, 0.5511 [0.528, 0.575]) is weaker than step length's
*fifth*-best. The direction claim does survive: under the flipped sign (positive = curvier)
GatedAnneal and TopK fall below chance (0.4973, 0.4904), so violations are straighter, which
is the RECURVE (Shin et al., NeurIPS 2024) direction and the straightness study's own.

**The space ordering roughly inverts: Spearman ρ ≈ −0.67.** GatedAnneal is 1st on step
length and 8th on curvature; CosineSpaDE is 6th on step length and **1st** on curvature, and
is the one space where θ beats d (0.5511 vs 0.5399). Standard flips the same way (0.5193 vs
0.5082). So "which dictionary carries the violation signal" is not a property of the
dictionary — it depends on which geometric quantity is measured.

A hypothesis for the CosineSpaDE flip, testable and not established here: a sparsemax code
lies on the simplex and sums to 1, which bounds how far a step can travel, so magnitude
information is compressed out and angular information is what remains. That is the same
geometry-vs-magnitude question the un-run norm baseline is about.

## Corrections to the README this run forces

- **"The `theta` block scores 0.53-0.58" does not reproduce under either contrast.**
  Measured: **0.500-0.551** against the matched legal control, **0.539-0.616** against the
  clean reference. The qualitative claim is confirmed and if anything understated, but the
  range should be replaced with measured numbers.
- **The straightness geometry npz does carry `norm`** (shape 10000x58), so the norm-only
  baseline the README calls blocking ("needs one GPU encode pass") is already runnable on
  the regenerated corpus. Only `curvature_discriminant`'s npz lacks it.
- **No NaNs.** A nan-fill was built in for zero-length steps in sparse codes; the count was
  0 in all nine spaces, so nothing was imputed.

`$SPADE_STRAIGHTNESS_DIR/geometry/`; writes nothing.

3,185 branch-complete games.
